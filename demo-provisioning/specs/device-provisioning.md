# 裝置佈建規格

## REQ-001 裝置註冊
系統應允許以唯一的 MAC 位址註冊新裝置,初始狀態為待佈建（pending）。重複的 MAC 位址應被拒絕。

## REQ-002 佈建成功
佈建成功後,裝置狀態應由待佈建（pending）轉為已佈建（provisioned）。

## REQ-003 佈建重試
裝置在佈建階段無回應時,系統應重試最多三次,採指數退避（1s / 2s / 4s）。三次皆失敗則將狀態標記為 provision_failed 並寫入錯誤記錄。

## REQ-004 狀態轉換限制
已撤銷（revoked）的裝置不得直接轉為已佈建（provisioned）,須先回到待佈建（pending）。

## REQ-005 API 查詢
API 應提供以 MAC 位址查詢單一裝置狀態的端點,找不到時回傳 404。
